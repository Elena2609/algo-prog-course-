# algo-prog-course-
ПР1.Ответы на контрольные вопросы
1. Чем компилируемый язык (C#) отличается от интерпретируемого (Python) с точки
зрения того, когда обнаруживаются ошибки?

В C#(компилируемый) ошибки выявляются на этапе компиляции: компилятор проверяет весь исходный код до запуска. Если есть синтаксическая ошибка, программа не соберется и не запустится вообще, даже если ошибочная строка не выполнялась.
В Python ошибки обнаруживаются во время выполнения: интерпретатор читает и выполняет код построчно, поэтому об ошибке можно узнать, только дойдя до ошибки

2. Что делает команда dotnet run на самом деле — из каких двух шагов она состоит?

1.Сборка проекта(build) - компиляция .cs файлов.
2.Запуск получившейся программы.

3. Зачем нужны папки bin/ и obj/ и почему их не нужно хранить в Git?

bin/ - сюда компилятор кладет скомпилированную программу(результат сборки).
obj/ - служебные промежуточные файлы сборки.
Эти папки не являются исходным кодом, они создаются заново при каждой сборке в конкретном компьютере. Их не нужно хранить в Git, потому что они воспроизводятся командой dotnet run. Для этого существует файл .gitignore.

4. В чём разница между git commit и git push?

git commit создает снимок (коммит) изменений локально в вашем репозитории.
git push отправляет эти локальные коммиты на удаленный репозиторий(например, Git Hub). То есть commit фиксирует изменения на компьютере, а push синхронизирует их с облаком.

5. Чем отличаются конкатенация строк через + и интерполяция через $"..."? Какой способ предпочтительнее и почему?

Конкатенация через + просто склеивает строки, но при большом количестве переменных код становиться громоздким и плохо читаемым.
Интерполяция через $"..." позволяет вставлять значения переменный прямо в тест с помощью фигурных скобок.
Предпочтительнее интерполяция, так как она улучшает читаемость кода и снижает вероятность ошибок.

6. Что произойдёт, если разделить int на int, если результат должен быть дробным? Как это исправить?

Если оба операнда - int, результат деления тоже будет int(дробная часть просто отбрасывается, не округляясь).
Чтобы получиь точный результат, нужно превратить хотя бы один операнд в double - это делается через (double) перед переменной, это называется явное приведение типов

7. Чем const отличается от обычной переменной? Приведите свой пример, когда стоит использовать const.

const - это константа, ее значение задается один раз при объявлении и н может изменятся во время работы программы. Обычная переменная может менять значение. Используется для постоянных велечин, например, ставка НДС.

8. Что такое top-level statements и чем они отличаются от классического class Program{ static void Main() }?

top-level statements - начиная с C#9, для простой программы не нужно писать class Program { static void Main() } вручную, компилятор достраивает все сам.
